# Glow and Go

Migracao inicial do projeto Lovable **Glow & Go** para GitHub.

Projeto original Lovable: https://lovable.dev/projects/ef980582-b39a-4764-8ea9-c3b485a24179

## Status

- Primeira versao funcional em React + Vite.
- Publicacao preparada via GitHub Pages workflow.
- Landing page inicial para captacao via WhatsApp.
- Qualificacao avancada e integracoes ficam para segunda etapa.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
